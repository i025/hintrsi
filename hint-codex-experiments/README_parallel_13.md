## 修改范围

| 文件 | 修改与原因 |

| `source_parallel_13/codex_cli_bridge.py` | 使用无原生工具的模型配置，关闭原生功能入口；不向决策模型注入宿主机权限和目录说明。明确空 `tool_calls` 会结束整个 SDK 任务，未完成实现时应返回下一次外部工具请求。 |

| `source_parallel_13/benchmark/deepswe/prompts/deep_swe_user_prompt.md` | 在原有步骤前增加英文无人值守实施要求，说明完成实现与验证后再结束、工作区可写及 main 已准备好。没有加入解题线索。 |

新增两个回归测试文件位于 `tests_parallel_13/`。`preflight/launch_parallel_13.py` 沿用第 12 版启动器，仅更新版本和记录路径；不带 `--launch` 时只检查服务与六套环境。完整生产差异在 `reports/parallel_13_changes.diff`，源码归档在 `reports/parallel_13_source.tar.gz`。

各组使用相同的接入、工具与任务完成要求。模型仍为 gpt-6.1-terra / low，B/H/M/I、H/M 共用首轮、最多五轮、8 CPU / 128 GiB、SDK 会话管理和自动压缩、轮内指导的 20/3/100/600 设置不变。初始 SDK 工具从 18 个变为 17 个，移除项为 Skill。

没有添加自动修补模型输出、根据空补丁重新采样或强制续跑的逻辑。最终回复仍按原 SDK 的结束规则执行；判断是否完成实现通过真实轨迹、代码差异与测试结果验证。原有的额度停止逻辑保留。

## 结果边界

失败请求回放只生成下一步操作，不执行正式题目的这些操作，不能算正式题目已解决。完整 SDK 小题是独立夹具，轮内指导夹具要求先做二十次独立数据读取，以触发原来的检查间隔；不作为 DeepSWE 成绩。

这些修复会改变工具呈现、任务完成说明和工作分支初始化，后续必须作为统一的新版本比较，不能混入第 12 批的统计。CLI 的角色封装与原 API 的原生角色通道及采样参数仍不完全等价；本次没有改变这一既有边界。

原镜像中的 SDK 内层命令隔离报告缺少 bwrap/socat；本版保持该环境不变。容器、原网络规则和教师的只读挂载仍生效，不能把 SDK 的 enabled 配置描述为内层隔离已实际启用。

本次真实模型请求共 64 次，全部返回用量，总计 3,141,263 token，包含未解决问题的前期回放，不只计算成功检查。无未知用量，未推算实际美元费用。模型请求时间跨度为北京时间 16:42:05 至 17:18:16，约 36 分 11 秒；不等于整个代码修复用时。逐次 token 与耗时保存在桥接原始账本，汇总见 `preflight/parallel_13_fixes/usage_summary.json`。

未使用 GPU、Ofox 或新增环境安装。验证使用已有只读运行时与新建临时容器，宿主机 Codex 的状态写入独立验证目录，不修改用户的全局配置。没有新增文件哈希校验。
