## 改法

CLI 仍使用 `--sandbox read-only`，继续只返回结构化决策。桥为含工具的请求加入英文 `sdk_execution_context`，明确执行器位于另一个 SDK 容器，原权限模式为 `bypassPermissions`，仓库为 `/app`：学生容器可写，教师仓库只读。模型输出的工具请求仍交回原 SDK 执行。

这是容器的实际访问范围；SDK 对话中的角色限制、只读子 Agent 和真实工具拒绝仍然生效。学生路由中的 Explore 子角色不会因此获得写权限。教师可以按原提示写 `/tmp` 分析产物，不能修改仓库或参考补丁。纯文本 Hint 压缩不接收这份容器权限信息。

原始 messages、工具定义、参数、学生和教师任务提示均完整保留。沿用第 11 版的结构化参数编码修复，不恢复双层 JSON 字符串。模型仍为 `gpt-6.1-terra` / `low`；轮数、资源、原 SDK 的会话恢复和自动压缩配置不变。新增内容全为英文，不向学生增加 GT 或解题指导。
