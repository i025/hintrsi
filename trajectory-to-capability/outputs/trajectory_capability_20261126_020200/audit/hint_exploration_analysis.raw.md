### 可选 Hint 探索：观察性补充

本节是单个 Development 任务的可选探索，不是新的迁移测试。四次运行从相同初始代码出发，使用独立的新 SDK 会话和容器，并非从同一中间状态恢复的反事实重放。首个实际请求的核验显示：四组的系统消息、非系统消息和工具定义均与 NoHint 相同，均无持久能力标记；这支持初始请求相等，不意味着后续轨迹相同。主要四组 Test 知识库在这些可选试验前已全部冻结。

**实际交付与风格。** 三个有指导组均在工具计数 20 时完成一次服务端教师检查：先生成候选，再由独立筛选调用批准，最终各交付一条 Hint。Error、Strategy、Exploration 的 SDK 回调数分别为 2、1、2；前后两组在计数 40 的第二次回调返回空 Hint，并未产生第二次服务端检查。每组两次教师模型请求是候选和筛选，而不是两条指导。NoHint 的回调、检查、教师请求和交付均为零。组名本身不能证明某种风格已交付；这里比较的是筛选后实际进入请求的文字，而非候选诊断。

- **Error** 的 38 词指出复现直接注入工具事件，询问 Anthropic 提供方在真实对话中能否请求并发出委派事件，并要求比较发出请求、流解析与处理器预期。它确实聚焦复现的错误盲区，但也以探索和策略问题表达，并非纯粹报错。文字进入实际请求第 7 次，之后共出现在 9 次请求中。此前学生已检查提供方；其后事件 43、46–56 识别并修改提供方相关路径，与提示相符，但未显示真实 Anthropic 会话。见 [Error 审计与轨迹出处](posthoc_hint_exploration_claude-code-by-agents-recursive-delegation_Error.md)。
- **Strategy** 的 44 词同样指出直接注入的局限，进一步询问工具发现、发出及后续上下文，并建议模拟提供方 API 往返；它符合策略性指导，但混有错误诊断和探索。文字进入请求第 8 次，共出现 13 次。之后事件 55 涉及上下文和提供方，事件 68–74 建立模拟 API 往返：首次断言失败，调整断言后通过；这不是实时提供方验证。[Strategy 审计](posthoc_hint_exploration_claude-code-by-agents-recursive-delegation_Strategy.md)。
- **Exploration** 的 27 词要求模拟流式工具调用，比较发出请求及响应与处理器启动委派的需要；它符合实验式探索，但也给出具体测试策略，并非纯探索。文字进入请求第 9 次，共出现 9 次。之后事件 46–54 搜索并运行提供方模拟：起初未见序列化工具字段，仅有 done；事件 55–62 修改相关路径，事件 72 的模拟输出则展示工具及 tool-use。此前学生也已阅读提供方代码。[Exploration 审计](posthoc_hint_exploration_claude-code-by-agents-recursive-delegation_Exploration.md)。

实际请求包含文字证明了暴露，不单独证明采纳；上述可执行动作与提示内容吻合，但先后顺序和学生自述均不能证明因果。NoHint 也自行检查处理器和提供方，并制作直接注入事件的复现：事件 27–30 中子代理未被调用，事件 52–54、69–70 中该窄场景通过。这说明无 Hint 也可能开展类似探查，并不证明完整契约通过。[NoHint 审计](posthoc_hint_exploration_claude-code-by-agents-recursive-delegation_NoHint.md)；候选、筛选和交付见 [教师记录](../logs/hint_progress/progress.jsonl)。

**结果与成本的解释。** 三个有指导组的正式即时结果均为成功 1、F2P 7/7、P2P 31/31；各自评测标准错误也出现 Node 堆内存耗尽信号，原因及对额外覆盖的影响未知，不应抹去已报告成绩，也不能据此声称其他测试通过。局部测试中，Error 和 Exploration 均有处理器测试断言失败；缺生成文件、缺构建产物及重复命令参数则是设置或调用问题。Strategy 的部分测试细节仅见学生总结，不能当作独立核实的失败原因。

NoHint 学生正常结束，但正式评测超时、退出码 137，奖励及 F2P/P2P 均缺失，不能算普通算法失败或成功。首次可选评测在容器创建约 600 秒后外部停止，执行确切起点未知；之后才为可选评测加入限时包装，因而计时并非严格一致。无同补丁重试，根因未知。它是评测中断，而非截止期跳过；本节四次均已运行。[首次限时记录](../logs/optional_evaluation_timeout_NoHint.json)。

按 NoHint、Error、Strategy、Exploration 顺序，学生模型请求为 21、15、20、17 次；输入 token 为 1,469,243、979,072、1,399,204、1,222,345，输出为 4,770、5,238、6,183、5,644；SDK 时间为 841.202、629.996、894.899、679.903 秒，墙钟时间为 1646.474、964.512、1233.5、1052.6 秒。教师输入／输出 token 分别为 0／0、312,108／244、309,752／257、329,195／214；SDK 教师等待分别为 0、18.140、20.759、18.792 秒。上述成本是实际观测，不代表指导机会之外的耗时条件完全相同。

候选性、尚未验证的可迁移观察是：直接注入事件的模拟可检验处理器边界，却可能绕过上游事件产生路径；分开检查提供方请求与流响应能观察另一边界。但本证据不足以支持 Hint 风格效应或长期轨迹学习价值排序；未进行独立 Hint 到知识的迁移测试，未形成新 skill，也未更新主库。
