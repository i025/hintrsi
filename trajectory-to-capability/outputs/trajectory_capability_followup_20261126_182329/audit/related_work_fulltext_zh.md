# 近邻工作边界报告

本报告依据九篇官方全文的既有 CLI 审阅记录，界定机制重叠与待比较问题，并非全文系统综述。文本提取涵盖可见段落和图表字幕，但未逐图视觉核查所有论文图像；下述论文结果均为作者报告，非本次实测，也未复现。

**已有机制。**轨迹总结、成功失败对比、教师指导、固定权重下的提示或技能更新、候选验证，以及修复与退化评价，均已有近邻，不能单独作为创新主张。[GEPA](https://arxiv.org/html/2507.19457) 从执行轨迹及反馈反思并演化模块提示，以小批次表现筛选候选，而非更新权重（§3，00212–00234、00270–00283）。[DoVer](https://arxiv.org/html/2512.06749) 在失败轨迹的重规划处介入，恢复上下文和状态后重复执行，用成功率及里程碑进展检验假设；它优化单次消息或计划，不等于蒸馏可复用技能（§4.1–4.2，00134–00172）。

[Trace2Skill](https://arxiv.org/html/2603.25158) 分别分析成功与失败轨迹并合并技能补丁，错误分析会检查产物和验证修复；默认合并与实验性的候选子集评分应予区分（§2.3–2.4，00135–00153；§4.3，00585–00597）。[SkillGen](https://arxiv.org/html/2605.10999) 依据输入与摘要的嵌入检索相近成功案例，对照完整轨迹；在相同验证输入上以修复数减退化数评价候选，并经择优和正增益门槛部署（§3.2–3.3，00122–00126、00170–00212）。验证数据参与迭代和选择，不应与独立测试混同（§4，00217–00221）。

[SKILL-KD](https://arxiv.org/html/2607.28048) 对照同任务的教师与失败学生轨迹，以学生重跑验证补丁；单实例成功不证明普遍有效（§3.1–3.3，00139–00191）。[Socratic Skill Learning](https://arxiv.org/html/2610.17860) 中学生测试建议、编辑资源包，教育者审阅工作，问题关闭要求课后检查；其适配基线也包含轨迹合并和教师—学生对照（§4.1–4.3，00344–00407；附录 C.3，01226–01274）。

其他近邻同样涉及状态或验证。[SimWorld Studio](https://arxiv.org/html/2605.09423) 从失败的动作—观察轨迹生成规则，并用场景图与视觉语言模型检查场景，但未明确独立技能候选选择（§3.3，00525–00526；附录 C.2，01210–01215）。[SceneEvolve](https://arxiv.org/html/2610.37046) 依据当前几何检查空间关系，并在相同预算下按开发分数选择整套工具与技能；这不是单项技能验证（§3.2–3.3，00119–00142）。[Liu 和 Wu](https://arxiv.org/html/2611.13144) 的技能跟踪进度、任务语义及后置条件，候选须在匹配开发任务上优于空库，但部分估计仅依赖一个复用任务（§3.3，00186–00191；附录 C.2、C.6，00825–00839、00955–00956）。

**更具体的比较边界。**目前发现的问题不是泛称“从轨迹学习”，而是在证据和预算固定时，比较按程序状态变化及功能约束对齐后提取经验，与按时间顺序提取经验的差异。它在目的上与上述语义匹配、状态恢复、产物检查和教师对照明显重叠；可能的区别在于是否跨轨迹对应功能等价的程序状态，再比较相关变化与约束。上述审阅记录未见这些工作明确隔离该比较；这不是证明不存在其他实现，也不是新颖性肯定结论。术语不同本身不是创新证据。当前扩展实验仍在运行，结果未知；本报告不修改实验或能力库。
