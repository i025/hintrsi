[Liu and Wu](https://arxiv.org/html/2611.13144) optimize reusable advisory skills for a fixed model and harness—not weights. Both teachers use their own student executions and feedback; the aware teacher additionally models failures and probes task-property changes. This overlaps trajectory distillation, teacher guidance and fixed-model adaptation, but is not a matched-trajectory contrast (§§3.1–3.2, lines 00173–00185).

Skills track progress, task semantics and postconditions, overlapping program-state concerns; the paper specifies no cross-trajectory functional-state or semantic alignment procedure (Appendix C.2, lines 00825–00839). It does not compare functional-state-aligned with chronological extraction under fixed evidence and budgets.

For skill verification, candidates must improve standalone acceptance against an empty library on one to four matched development tasks; deployment selects by student choice, category utility, or flat injection (§3.3, lines 00186–00191). Some admission estimates rely on one reused task (Appendix C.6, lines 00955–00956).

The authors report teacher-free gains and reciprocal advantages for student-specific libraries, although some exchanged libraries help (§§5.2–5.3, lines 00358–00360, 00402–00403). Evidence is concentrated in one principal pairing, with few control seeds and selector dependence (§6, lines 00452–00454). We did not replicate these results.
