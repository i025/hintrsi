## 十个问题

### 1. 直接检查开发 GT 实际发现什么？

开发研究记录称 Blender 实际打开三份 `.blend` 并查询变换、父子关系、网格材质与 UV、节点、图像打包、相机和灯。三个相机均为透视、15 mm 镜头；A5 的查询还记录 32 mm 传感器宽。S01 和 S03 的门资产分别有门对象父级；S02 床垫有床对象父级。S01/S03 所查图像数据块仅有 Render Result；S02 有一个打包文件图像。S02 瓷砖材质与 S03 材质存在 Object 坐标、Mapping 和程序化网络；S01 查询还看到节点组和不同网格 UV 可用性。S01/S03 各有三个 area lights，S02 另有 point light。它们是具体场景存储内容，不是重建的唯一答案或最优参数。节点组内部和外部图像存在性未完全审计。记录为开发学习者的直接查询报告，比较审查没有独立重查所有原始查询输出：`acquisition_reviews/library-audit/AUDIT/workspace/library_audit.json:65-83`；`acquisition_reviews/knowledge-comparison/COMPARISON/workspace/knowledge_comparison.json:18-24,84-92`。

### 2. A1–A5 库有何实质差异？

按冻结库审计，A1 有投影、地标残差、AABB 支撑筛查、场景图关系和方向性噪声材质；A2 另有相机朝向、铰链变换、采样垂直支撑和 AABB 分离；A3 将空间、支撑、外观分模块，含铰链自由边**候选位置**而非场景铰链变换、采样支撑及独立 world AABB；A4 有相机朝向、铰链变换、AABB 支撑和父子组件；A5 有铰链变换、采样支撑、AABB 分离和地标残差。所有库都有投影与方向噪声材质，但参数、坐标系和实际操作不同。A4 锚点保持测试并未证明完整装配：验证时父级化使腿和把手跳位。A5 最初学习测试在投影断言处失败，修正后重跑才到达铰链和材质，另有独立合成验证。合成节点链接或旋转单姿态不证明真实渲染改善、无碰撞或接触。`acquisition_reviews/library-audit/AUDIT/workspace/library_audit.json:7-103`。

部分测试前审计没有在公共文件发现完整旧场景、专用纹理或 GT 加载路径；参数默认值和合成样例本身不是泄露答案的证据。审计是部分覆盖，不证明绝无泄漏。各库冻结记录大小分别为 A1 1,233 词/102 非空 Python 行，A2 917/120，A3 1,046/109，A4 1,005/101，A5 918/106；不构成内容匹配消融。

### 4. 学生实际使用了吗？

20 个 A1–A5 初始请求都包含本库 SKILL 文本和挂载提示，A0 没有库；这只是暴露，不是后来 Read、import、实际执行到函数调用或明确归因的手写重实现。自动技术记录例如 A-T01-A1 的完整轨迹和 `build.py:1-92` 未见后续库读取、导入、调用或引用重实现；A-T02-A4 的轨迹为目录查看、写源码、一次 Blender 执行，也未见后续库读取或调用。A-T01-A2/A-T04-A2 完全无工具调用。A-T03-A0 无库也构造映射程序噪声地板，因此类似代码不能单独证明知识转移。另有部分库文档写生成时路径而实际挂载路径不同；初始通知给出实际路径，对行为的影响未知，不能归因两次失败。证据：`acquisition_reviews/technical/A-T01-A1/workspace/technical_annotation.json`、`acquisition_reviews/technical/A-T02-A4/workspace/technical_annotation.json`、对应 `runs/A-T01-A1/` 与 `runs/A-T02-A4/` 的 SDK 事件及源码；`ENGINEERING_LOG.md:12-14`。这是选定案例和自动审查，不排除初始文本影响，也不把验证者调用算成学生调用。

### 5. 相对位置、朝向和空间关系改善了吗？

局部二维重叠有改善也有退化，不能概括为全面改善。除开头实例，A-T02 地毯 ID 59 的 A4/A1 IoU 为 0.457/0.175；A-T04 柜子 ID 67 的 A1/A0 为 0.348/0.678。A-T03 A3/A2 的洗碗机 ID 23 为 0.270/0.391。投影 IoU 既受镜头也受形状、遮挡和对应影响，质心距离与 IoU 可反向；没有对齐世界坐标的 3D 方位或角度误差。窗口图例见上述 `mapping_002/`；A-T02 床垫例见 `runs/A-T02-A4/analysis/projection/mapping_000/` 与 `runs/A-T02-A1/analysis/projection/mapping_001/`。205 个原始对应提议中机械合并 192 个实际判断，A-T02-A3 的 13 个未审项保持 unknown；两次无场景运行无提议。`ENGINEERING_LOG.md:25-31`；`analysis/paired_projection_differences.json`。

### 6. 材质、纹理映射和外观改善了吗？

没有可靠的普遍改善结论。自动视觉估计与 SSIM 的差值表显示任务依赖且指标常分歧，例如 A-T03 的 A5−A3 视觉 −8、SSIM +0.0706；它们都不是单独的材质质量测量。技术审查称 A-T02-A2 使用平坦材质及几何桌面条纹，未记录调用 `mapped_stone` 或受控材质/中性光比较；A-T03-A0 则无库仍有映射噪声地板。公共库的方向性材质节点链在合成验证中有连接输出证据，但没有相应视觉质量比较。更多节点不自动更好。22 个学生与四个 GT 的共同白光辅助渲染虽完成，仍保留几何、相机、材质和自发光混杂。原图与输出分别见数据分割所列 GT `color.png` 及 `runs/<run>/workspace/final.png`；有关具体产物位置以各运行记录为准。`ENGINEERING_LOG.md:18-19`；`acquisition_reviews/library-audit/AUDIT/workspace/library_audit.json:17-22,36-43`。

### 7. 主动探索比普通策略指导迁移更好吗？

无法认定。预设 A3−A2 的四个任务中仅 A-T02、A-T03 双方有图，自动视觉差分别 +7、−6，SSIM 分别 −0.0055、−0.0001；其余两项因 A2 无交付为 null。A-T03 烤箱和洗碗机的同 ID IoU 还偏向 A2。探索历史确有实际候选及检查：S01-E4-R1 记录侧视图及最终保留修改后的脚轮；但 S02-E4-R1 的门候选 G 在最终场景后渲染、没有保留，迁移或完整修复均不能由此推断。原历史记录由知识比较和开发学习证据索引，审查并未穷尽所有事件。`acquisition_reviews/knowledge-comparison/COMPARISON/workspace/knowledge_comparison.json:20-23,62-66`。

### 8. GT 提供了什么额外价值？

直接提供相机、父子关系、节点与图像打包等开发场景的可查询事实，帮助校准假设，不等于提供了独立测试答案。A4−A1 在 A-T02 的自动视觉 +7，床垫和地毯同 ID 二维 IoU 也较高；在 A-T04 自动视觉 −5，虽然一些对象 IoU 较高且 SSIM +0.0748；A-T01 视觉持平、SSIM 下降。A5−A3 亦为 +5、−1、−8、−1。故 GT 的观察价值明确，稳定的视觉或三维增益未建立。GT 查询不能单独证明任何新函数的唯一思想来源。

### 9. GT 与探索互补吗？

方法层面存在合理互补假设：GT 给出存储结构，探索轨迹提供候选、执行、侧视及保留决策；A3 的自由边计算与 A4 的铰链变换也不同。但 A5−A3 和 A5−A4 的任务差值混合，且 A5 不总是最好：A-T03 A5−A3 自动视觉 −8，烤箱 IoU 0.193 对 0.422；A-T02 A5−A4 床垫 0.258 对 0.371。因此功能互补不是已证实的效果协同。每组一个库和一个样本不能拆分来源、库内容和随机轨迹作用。

### 10. 回归和副作用是什么？

两次 A2 无工具、无交付是独立报告的交付失败，原因未知；不推断由路径导致。A4 合成验证中的父级化使组件跳位，是实际技术副作用，不应因 pivot 保持而称完整装配成功。A5 早期投影断言失败后才修正，不能把未到达行算作首次通过。A-T01 A5 窗户、A-T03 A5 烤箱和 A-T04 A5 对 A4 的沙发等同 ID IoU 下降如上；自动视觉与 SSIM 分歧也是评价风险。探索历史中门的侧诊断受阻、铰链和相交未得到充分验证；近零支撑间隙、AABB 重叠和父子关系均不证明接触或无碰撞。

## 结论限制

这是一次外部知识/工具库获取及独立迁移，不显示权重改变、模型内化、长期保持、持续递归改善或完成 RSI。教师、学生与自动评判使用同一模型，语义对应非人工验证，无人类标签；小样本、输入大小不匹配、随机轨迹和单库单样本限制因果解释。设计没有内容匹配的纯文本与可执行工具消融，故既不能把初始文本暴露当作函数调用，也不能声称工具胜过文本。部分历史记录、原始 GT 查询及逐项技术审查未被本报告穷尽；所有未知保持未知。
