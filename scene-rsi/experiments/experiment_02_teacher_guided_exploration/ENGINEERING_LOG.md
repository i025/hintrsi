Fixed guidance is appended to the common initial user task; the existing system-prompt/knowledge interfaces remain unmodified and disabled.

- During request-attribution auditing after core startup, the generic supervisor's legacy route was found to label all roles as student in bridge records. Role-specific session/status files were already correct, and those original teacher records are preserved. The API route now uses explicit visual/trajectory roles for later reviews. Future scene diagnostic teachers use diagnostic_teacher because the legacy code-task teacher route advertises a wholly read-only coding container, whereas this separate scene evidence workspace must permit writing diagnosis output. Both the original student route and diagnostic_teacher advertise the same writable output context; actual teacher restrictions remain the narrower Read/Glob/Grep/Write tools and the no-reconstruction-edit task. Student routes remain exactly /student/solve/v1, so this logging-only change does not alter any formal student model input or condition and requires no resampling. Teacher usage is grouped by teacher session directories rather than the legacy raw route label. The frozen student source snapshot predates this metadata correction.
- The synthetic evaluation fixture verified separate local floor heights: measured gaps +0.02000005 and -0.01000000 against planned +0.02/-0.01, plus a real visible door mask. Its first controlled-render test failed because the fixture attempted to write a baseline-state file into the intentionally read-only /inputs mount. The fixture now writes in /capture and copies that input from the supervisor before use. Formal students were unaffected; first failure logs remain.
- This probe also demonstrated Blender's default zero process exit after some Python exceptions. Runtime log auditing found two such Python tracebacks in S03-E4-R1, despite zero CLI exits. These are preserved student exploration errors; the controller did not repair their code. Analysis now records traceback captures separately and supplies stdout/stderr to trajectory reviewers. Independent evaluation uses --python-exit-code 1 for all branches, plus actual artifact/state/regeneration checks. The student wrapper and all student conditions remain unchanged. An exit code alone is never treated as success evidence.
- The controlled-render fixture then exposed Blender's prohibition on loading the currently open .blend as a library. Baseline diagnostics now retain their already loaded baseline camera/lights/world; only distinct candidate scenes import the baseline environment. The corrected synthetic fixture produced all required geometry measurements, door masks and fixed-camera/light renders successfully. This fix is confined to independent evaluation and precedes evaluation of any formal outcome.
