# Experiment 03-B: independent perceptual teacher baselines

Frozen before T0/T1 predictions. This experiment prepares human alignment; no human alignment has yet been learned. All actual model sessions use Claude Agent SDK 0.2.186 -> existing Codex CLI Bridge 0.163.0 -> gpt-6.1-terra, low. The latest Bridge disables CLI internal multi-agent features. The SDK, rather than CLI native tools, executes Read and Write. No Blender execution or GPU is required by these critics.

T0 receives a concise generic reconstruction fidelity instruction. T1 receives the identical instruction and JSON output specification plus only the user's provisional principle: for the few observed examples, object position, orientation, spatial relationships/proportions and materials/textures often matter more than very small support gaps. This is neither a fixed weighting nor formal human alignment. No case-specific target is named. Every critic gets exactly the actual reference and one actual reconstructed image, a fresh session, image-only anonymous /app, Read/Write, 300 seconds and 24 Bridge requests. No GT, code, prior score, previous teacher judgment, condition label, selection reason or other reconstruction is mounted in its workspace.

Twelve development cases are selected from the three old reference scenes before any current predictions; their researcher-only selection rationale is configs/development_cases.json. They include natural reconstructions, unguided continuation, altered material implementations, local geometry changes and the bedroom projection/structure counterexample. Selection reflects existing evidence and is not a success-only sample. These scenes have already been seen by the user and cannot be claimed as independent tests.

Independent cases will use two new reference scenes and Base Harness outputs, not capability-learning results. These references will not overlap Experiment 03-A formal tests. Scene-level grouping is preserved; no version of an old reference is treated as an independent scene. The independent manifest is frozen before its critic predictions. Development and independent labels are exported separately; independent human labels cannot be supplied to teacher adjustment.

The fixed case order is shuffled with Random(2026112803), then T0/T1 order alternates across cases. Exactly one independent critic session is run for each case-condition pair. Existing failure/timeout evidence is preserved; no outcome-driven resampling. Actual budgets may differ despite identical ceilings. Scores are automated estimates, not human ground truth or a sole validated metric. Request image metadata, SDK messages, model responses, tool results, usage, wall time, stop reasons and removed backend credentials are audited.

Initial outputs are copied into predictions/ and frozen before any human annotations. The anonymous offline HTML shows reference and candidate images, 0–100 coarse ratings, up to three visual defects and optional text, and same-reference pair comparisons. It hides source runs, experimental groups, teacher scores, GT, metrics and expected outcomes. Human fields remain empty until a real person exports and returns JSON.

T2 and T3 are pending interfaces only. Genuine development ratings may later support T2 examples and T3 critique-process evolution, with fixed base weights. New independent scenes remain held out from teacher adjustment. Single-rater feedback supports alignment with that rater only; no general human preference claim. No synthetic human labels, automated replacement of human labels or waiting for feedback is permitted in this batch.

The three logical roles are kept distinct: Perceptual Critic runs now with RGB alone; Technical Diagnostician can later inspect student state/code/trajectory in either no-GT or authorized development-GT mode; Exploration Teacher can later create guidance from that diagnosis. This experiment runs only the perceptual baseline, not online student guidance or capability acquisition.

CPU affinity 48–55, one worker, port19265; nice15 and existing per-process32GiB limit. No extra packages, data download, environment mutation, reconstruction strategy or scene repair. Stop starting model sessions one hour before UTC2026-11-28 10:10:58 and preserve true results. Scientific and software changes are indexed without hashes/checksums. Existing Experiment01/02 data are read only.
